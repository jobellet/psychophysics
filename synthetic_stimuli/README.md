# Synthetic Stimuli

This folder contains Python code for designing parametrically controlled stimuli that can be used across different psychophysics experiments. The code here is not used directly in experiments but provides reusable components for generating synthetic stimuli.

## Structure

Each subfolder should contain a specific type of synthetic stimulus generator or a collection of related generators. For example:

- `grating/` - Grating stimuli with controllable spatial frequency, orientation, contrast
- `noise/` - Noise patterns with controllable statistics
- `motion/` - Motion stimuli with controllable direction, speed, coherence
- `shape/` - Geometric shapes with controllable parameters
- `color/` - Color stimuli with controllable chromatic properties

## Usage

Stimuli generated by code in this folder can be:
1. Pre-generated and saved as image/video files in the `assets/` folder
2. Generated on-the-fly during experiments using the shared resources
3. Used as base classes for experiment-specific stimulus generation

## Adding New Stimuli

When adding new stimulus generators:
1. Create a descriptive subfolder name
2. Include a README explaining the parameters and usage
3. Follow Python best practices (type hints, docstrings, etc.)
4. Consider adding example usage or test scripts
